# Pizza Ordering App

A simple beginner-level Pizza Ordering application built with **C#** and
**.NET Framework** using **Windows Forms**. This project represents my
first steps into C# development and desktop app programming.

## Features

-   Choose pizza size
-   Select toppings
-   Automatic price calculation
-   Simple and clean UI

## Technologies Used

-   C#
-   .NET Framework
-   Windows Forms

## Purpose

This project was created for learning and practicing C# fundamentals,
Windows Forms controls, and event-driven programming.
